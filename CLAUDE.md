## Working rules
- **Never display default values as if they were live.** Only rate values pulled from (or verified against) a live official web source may be presented as current. Hardcoded seed/fallback values are a safety net only: they carry `Provenance: seed_fallback` + `confidence: unverified`, export as `provenance: "seed"`, and the site hides them by default behind a labelled "Estimated" toggle. Never dress up a static default as a live-scraped rate.
- **Do not assume scope.** If a requirement is unclear or has multiple reasonable interpretations, stop and ask the user which path to take before proceeding.

## Architecture
- **Scrapers** (Python) live in `scrapers/utilities/`: 34 implementations plus `__init__.py`. The registry references 33 modules for 87 utility entries (8 Ontario entries `merged`, 1 Alberta gas entry `retired`); legacy `toronto_hydro.py` is unregistered and Ontario shares one data-driven scraper. Shared helpers include `scrapers/utils/oeb_tariff.py` (Ontario tariff sheets) and `scrapers/utils/alberta_rolr.py` (Alberta Rate of Last Resort UCA cross-check and term gate).
  Each inherits from `scrapers/base.py:BaseScraper` and returns `list[TariffRecord]`.
- **Pipeline** scripts in `pipeline/` handle orchestration: `run_scrape.py`, `export_json.py`, `representative_models.py`, `diff_report.py`, `validate.py`.
  - `run_scrape.py` uses upsert logic (`ON CONFLICT ... DO UPDATE SET`) with NULL-safe `IS` comparisons for idempotent re-runs.
  - `representative_models.py` (Phase 7A crosswalk coverage + 7B engine, `METHOD_VERSION` "7B-2"): `export_json.export_all()` calls `export_representative_models()` after the other exports (`MODEL_PROVINCES = ("ON",)`, `zone_policy="median_of_zones"`) and writes `site/data/representative_models.json`. CLI: `python -m pipeline.representative_models --coverage` and/or `--build [--output PATH]`.
- **Model inputs** in `data/models/`: `crosswalk.json` (224 ordered rules, first match wins), `usage_levels.json` (usage levels, days per month, kVA power factor, TOU/ULO shares, seasons, `reference_customer` list), `taxes.json` (13 jurisdictions x electricity/gas x residential/commercial lines of kind `sales_tax` or `rebate`).
- **Market history** (Phase 6A): `scripts/generate_market_pricing.py` (manual; not in any workflow) writes `site/data/market_pricing_ontario.json`, read by `scrapers/utils/market_pricing.py` and the site's Market Pricing view (rules under Key patterns).
- **Database** is SQLite at `data/db/rates.db`, schema defined in `schema/create_tables.sql`.
- **Static site** in `site/` is a single-page app (plain HTML+CSS+JS + Chart.js CDN), deployed to GitHub Pages, reads JSON from `site/data/` (`representative_models.json` is exported but not read yet; Phase 7F).
  - Three views: **Rate Browser** (filters/cards/details), **Market Pricing** (observed legacy HOEP 2020-2024 + Class B GA: heatmap/chart/summary/methodology; a "not available" notice replaces it unless the file is observed), and **Compare** (two tariffs, no calculated totals). The planned Across-Canada comparison in README Phase 9 is not implemented.
  - `formatCharge()` prefixes "$" only for units starting with "$" (negatives as "-$1.85/day"; %, fraction and other units plain); values are HTML-escaped and the details modal has one "Charge" column.
  - Filters use a `filterState` object with JavaScript `Set`s — empty set = show all, non-empty = intersection.
  - Province filter cascades into utility filter — selecting a province hides utilities from other provinces.
  - Rate deduplication at load time: only the most recent effective_date per utility+tariff is shown.
- **Source registry** at `data/sources/registry.json` maps utilities to scraper classes and source URLs.

## Key patterns
- Scrapers try live HTTP fetch first, fall back to hardcoded seed data. Provenance is tracked, not flattened (see Working rules): live/verified records carry `Provenance: officially_verified` or `Provenance: live_parsed`; failed fetches call `mark_fallback()` (→ `Provenance: seed_fallback`, `confidence: unverified`). `export_json.derive_provenance()` maps this to a `provenance` field (`"live"`/`"seed"`) and the site hides `seed` by default.
- **Live parsers**: Manitoba Hydro and NB Power use class-specific HTML parsers. BC Hydro/NSPower residential service, FortisBC Electric, Hydro-Quebec, Maritime Electric, Newfoundland Power and NL Hydro use PDF extraction; BC Hydro/NSPower business service remains HTML-based. SaskPower parses 41 records across audited building schedules and retained references. SaskEnergy and Centra Gas parse official HTML service variants with required dated carbon evidence. FortisBC Energy and Liberty NB parse official HTML tables plus official carbon evidence; Energir follows its pricing page to the current tariff PDF; Eastward follows its business page to the monthly rate-table PDF and cross-checks page summaries. Alberta wires parse AUC-approved schedule PDFs discovered each run (ENMAX opaque asset link, ATCO `rates.model.json`, EPCOR dated DAS/SAS/rider PDFs, FortisAlberta newest in-effect edition); the RoLR providers parse their pages/price schedules; Enbridge parses the Rate Handbook PDF, ATCO Gas the North/South schedule PDFs plus the DERS default-rate page, and EPCOR Ontario gas its rates pages verified against OEB documents.
- **Multi-class coverage is not catalogue completeness.** Every active registered utility except AESO has live output; optional products, open decisions and missing classes still require audits. Current counts are in the matrix.
- **Territories:** NTPC parses the PUB June 1, 2026 schedule (zones; per-community government) with GNWT Cost of Living Subsidy as a conditional credit and the TPSP printed first-block price as a conditional alternative energy price (never a derived difference). Qulliq uses the April 1, 2025 interim rates (medium confidence; stale page date label). Yukon Energy and ATCO Electric Yukon share the text joint YECL/YEC rate book cross-checked against the R/J cross-reference; same 20 schedules, not 40 classes.
- **Logging:** `setup_logging()` is idempotent and keeps pdfminer/pdfplumber at WARNING; per-token pdfminer DEBUG once grew `logs/scrape.log` to ~10 GB and stalled the suite. The file now rotates at 10 MB with 3 backups; it is a git-ignored debug diary that nothing reads.
- **Reviewed transcription (Centra MLI only, user-approved):** values from scanned image-only pages live in a module constant, are marked live at medium confidence, and are built only while the page-image SHA-256 hashes, edition headers and text cross-checks match. Never extend this to other image-only sources without explicit approval.
- **BC Hydro:** RS 1901/1904 exclude 2101 TOD adjustments; prorated tiers and conditional transformer discounts retain their source context. Business power-factor bands are conditional and fail independently.
- **NSPower:** FAM/DSM/storm are separate from base energy; closed pilots are conditional, never proof of participant restoration. November prices are date-gated and unsupported 2027 dates fail closed.
- **Hydro-Quebec DP/DM/DN:** multiplier-based units, additive dwelling/room terms and alternative voltage credits must not become invented fixed allowances or bill totals. Missing/future editions and missing continuations fail closed by class.
- **JS-rendered pages**: `BaseScraper.fetch_rendered_page()` uses headless Chromium; SaskPower needs it for PDF discovery. Missing known classes retain labelled seed fallbacks. Newly discovered unsupported classes are recorded as gaps, never invented as fallback rates.
- **SaskPower:** complete columns, dates and continuation pages gate each schedule independently; never put kVA thresholds in kW fields. E01/E03 columns must agree; bulk charges are per unit, and same-page schedules must be sliced separately.
- **SaskPower references:** E41 is per meter location per month during pumping season, not per season; its 1997 closure is not an effective date. Retain native units for irrigation, unmetered and oil-field schedules without expanding excluded processes.
- **Yukon Energy 1160:** use the base column, then separate R/J/J1 percentages, Rider F and dated energy-only relief. Other 1180-2480 classes come only from the text joint YECL/YEC book and must reconcile with the cross-reference; never read image-only PDFs into live values.
- **Alberta (batch 12):** transmission (SAS) charges are separate `transmission` components; current riders are separate dated components with quarter gates/end dates, and expired riders are excluded by date (ATCO Rider J = note). ATCO rows must reconcile to each printed TOTAL PRICE. EPCOR's "2026 INTERIM RATE" tariffs are live at medium confidence with an interim note (like Qulliq). kVA limits stay in eligibility text; municipal access fees/riders are notes. RoLR records require the UCA default-rates table (`scrapers/utils/alberta_rolr.py`) and fail closed after the fixed term until the next term is published.
- **Market-indexed parts** (Ontario non-RPP demand-class energy, EPCOR's SAS operating reserve) are value-less components (`charge_value=None`) with `market_reference` + `market_source_url`; the site shows "Variable". Observed averages belong in the market model, never in a tariff. AESO-tariff pass-throughs priced elsewhere (FortisAlberta Rate 65 transmission) are value-less; unpriced flow-throughs (ATCO T31 transmission) are notes.
- **Ontario market history (Phase 6A, done October 9):** `scripts/generate_market_pricing.py` (`--output`, `--start-year`/`--end-year` default 2020/2024, `--cache-dir`) downloads the IESO yearly hourly HOEP CSVs (`PUB_PriceHOEPPredispOR_YYYY`, $/MWh, hour-ending 1-24 EST) and the Class B GA "Actual Rate ($/MWh)" from the Data Directory workbook `Global-Adjustment-Values-MWh.xlsx` (cross-checked against the cents/kWh workbook). Every month's arithmetic mean must match the IESO HOEP Monthly Averages report (60 months; max difference 0.005, tolerance 0.01 $/MWh) and units must match the HOEP historic prices page, which must carry the retirement sentence; any missing month/day/hour or failed check writes nothing and exits non-zero. Output: 576 bins (month x weekday/weekend x hour beginning EST; a statutory holiday counts as its weekday) over January 1, 2020-December 31, 2024 (1,827 days, 43,848 hours; 101-112 hours per weekday bin, 41-46 per weekend bin) with `hours_count`, `avg_energy_price` (legacy HOEP), `avg_ga_class_b` and `combined` in $/kWh; `derivation_method` `observed_legacy_hoep_2020_2024_average`; metadata lists sources, hour convention, day-type rule, cross-check results and GA notes (April-June 2020 = published capped 115 $/MWh; 2021 actuals exclude the separate 5.01-7.09 $/MWh recovery rates). `scrapers/utils/market_pricing.py` loads only `observed_legacy_hoep_YYYY_YYYY_average` files (`get_observed_bin` replaced `get_representative_rate`; `get_monthly_average` weights by observed hours; tariff metadata formula "Ontario Electricity Market Price (DA-OZP + LFDA) + Global Adjustment"). The site labels the view as the pre-May-2025 legacy market and keeps an always-visible note that market-billed customers now pay the OEMP plus GA. Never copy these averages into a tariff; an OEMP history needs 12 months of self-archived daily DA-OZP files (not started). Open defaults (user may change): capped vs unadjusted April-June 2020 GA, adding the 2021 recovery rates, holidays counted as weekdays.
- **Cross-check sources fail closed:** UCA table for Alberta RoLR prices and the DERS gas default rate; OEB Decision and Rate Order Appendix A plus the QRAM notice for EPCOR Ontario gas; CRA fuel-charge page for zero federal carbon (Enbridge, ATCO Gas, EPCOR Ontario).
- **Ontario LDCs:** `OEB_TARIFF_DOCUMENTS` (registry name -> [{url, case_number, zones, default_zone}]) in `ontario_ldc.py`; `scrapers/utils/oeb_tariff.py` parses tariff sheets (use `extract_tariff_pages`, not `normalize_document_text`, which drops repeated lines). BillData XML = name/zone cross-check only. Residential/GS<50 = live RPP energy + tariff delivery, legacy codes (TOU-R, GS-TOU-S...) in the default zone and "[zone]" names elsewhere; demand classes = delivery + the Phase 6B value-less market component (see Market-indexed parts). Open-GS floor <= 1,000 kW -> commercial, else `large_use` (user-confirmed). A rejected class emits no new estimate (user decision: go by live sources); older stored estimates stay in history labelled seed. Seed suppression: a configured LDC with a class rejection or no such class (`gs:absent`/`demand:absent`) emits no Res/GS/GS-D seeds; a fetch failure or whole-sheet rejection keeps seeds; the street-lighting seed is kept.
- **Ontario tariff-sheet rules:** an overprinted "Applicable only for ..." tail attaches to the preceding rider; a lone Transformation Connection line is the standard connection rate (a lone Line line still fails); the case number may come from the Schedule A cover only when its date equals the Issued date; "EQUAL TO OR GREATER THAN" open GS and INTERMEDIATE USER (inside 50-5,000 kW) are GS demand; in-scope classes that classify "other" surface as rejections. User-confirmed readings: Hydro One Seasonal = R2 seasonal service charge + shared R2 lines, no RRRP credit; year-round R2 carries the RRRP credit as conditional; UR/R1 seasonal properties use UR/R1 records; DRP not modelled. Algoma R1 criteria (i)/(ii) split, both residential, R1(i) keeps TOU-R codes; R2 = `residential_demand` delivery-only record (no RPP, no 6B market energy).
- **OEB per-document settings:** `"extract": {"y_tolerance": N}` for PDFs whose values print above their labels (Kingston 6, Midland 1, Grimsby 4) and, for PUC Distribution only, `"connection_rate": "not_printed"` (the approved tariff prints no Retail Transmission Connection rate; every record carries a note). All other documents stay strict.
- **No-seed and retired entries:** new utilities without seed data (EPCOR Natural Gas (Ontario); Ontario successors Enova/GrandBridge) return no records when sources fail. `merged` (absorbed Ontario LDCs: `status: "merged"` + `merged_into` successor) and `retired` registry entries are skipped by `get_active_utilities` (which runs `active`/`partial`) and keep their history.
- **Representative models (Phase 7A/7B; Ontario electricity only):** comparison indicators with `provenance: "modeled"`; never a billed tariff, never live coverage, not yet read by the site (7F). The crosswalk's first matching rule maps each latest live record (site dedupe, then `provenance == "live"`) to {province, fuel, sector, structure, size band} or an exclusion reason (Alberta electricity `province_not_modelled_yet_7c`, ON/AB gas `gas_models_phase_7d`, territories `territory_planned_later`); 0 unmapped is required and the coverage report lists the 15 intentional rule overrides. Each utility counts once as the median of its standard zones (user decision; `default_only` is the alternative policy). Per-record costs include unconditional components in effect at the as-of date; conditional/alternative/optional/expired/not-yet-effective components, percentage adjustments and value-less market components are excluded and counted, except the reviewed `reference_customer` entries (Ontario Class B CBR riders, non-RPP Class B GA riders for demand sectors, non-wholesale-market-participant riders, SSS administration charge). $/day x 30.4375; kVA at PF 0.9; Ontario loss factors and Class A GA are not modeled (stated in the method text); no 5,000 kW+ usage level yet. Tax lines never compound: OER 23.5% of the pre-tax amount with HST on the pre-rebate amount, so Ontario residential/GS<50 costs with tax are below those without. Per level: median/n/min/p25/p75/max, closest utility, outliers > 30% from the median or outside 1.5 x IQR (n >= 3). States: `modeled`, `single_source`, `market_energy_pending` (Ontario demand classes), `not_computable`. The export hook imports lazily and writes via a temp file + `os.replace`; any failure is logged, keeps the previous file and never fails the export. Tests use frozen fixtures `tests/fixtures/rm_records_sample.json`, `rm_engine_sample.json` and `rm_records_b12.json`, so monthly CI pre-scrape tests never depend on the live export.
- Per-utility parser rules and remaining class gaps live in [the gap report](docs/live_parser_gap_report.md); use [the matrix](docs/phase5_completion_matrix.md) for the current queue.
- Every tariff stores individual rate_components (fixed, energy, demand, delivery, riders, etc.) — never flatten to one number.
- Historical snapshots are preserved in `historical_snapshots` table — never overwrite.
- Validation runs after scraping (`scrapers/utils/validation.py`).
- `confidence` field on tariffs/components tracks data quality: high / medium / low / unverified.
- **Change detection** (`scrapers/utils/change_detection.py`): `compare_to_seed()` pairs live-parsed records with seed data, flags changes by severity (info <5%, warning 5-30%, critical >30%). Critical alerts cause fallback to seed data.
- **Parsing helpers** (`scrapers/utils/parsing.py`): `find_text_near_label()`, `extract_rate_from_text()`, `detect_js_rendered()`, query-safe/relative-aware `find_pdf_links()`, and strict `verify_tariff_values()` official-source checks.

## Running
```bash
pip install -r requirements.txt && pip install -e .
python -m playwright install chromium     # headless browser for JS-rendered pages
python -m pipeline.run_scrape --init-db   # first time
python -m pipeline.run_scrape             # scrape all
python -m pipeline.export_json            # export for site (also writes site/data/representative_models.json)
python -m pipeline.representative_models --coverage   # Phase 7A crosswalk coverage of site/data/rates.json
python scripts/generate_market_pricing.py # Phase 6A: rebuild site/data/market_pricing_ontario.json (downloads IESO files; fails closed)
pytest                                    # run tests (1,683 tests across 8 modules)
```

## Adding a utility
1. New file in `scrapers/utilities/` inheriting `BaseScraper`.
2. Register in `data/sources/registry.json`.
3. Test with `python -m pipeline.run_scrape --utility "Name" --dry-run`.

## Phase 5 hardening conventions

- `BaseScraper.verify_official_records()` is the shared strict HTML/PDF component verifier; utility modules retain tariff interpretation. `mark_fallback()` recursively downgrades confidence and emits `Provenance: seed_fallback` notes; `mark_live_parsed()` stamps `Provenance: live_parsed` for scrapers that rebuild tariffs directly from a live fetch. `pipeline/export_json.py:derive_provenance()` collapses these markers into a `provenance` field the site uses to hide non-live data by default.
- `scrapers.utils.parsing` provides `DocumentPage`, page-aware fail-closed PDF extraction/section selection, CSV/XLSX readers, content hashing, effective-date/unit/currency normalization, and contextual verification.
- Snapshot serialization is canonical JSON with sorted component dictionaries. Ordering alone is ignored; all semantic fields remain hashed. `diff_runs` compares append-only per-run snapshots.
- The no-build comparison state is an in-memory two-item array in `site/js/app.js`; it aligns exact type/name/unit keys and never totals them.
- Deterministic tests block unmocked network access. Run `pytest -q` (1,683 tests across 8 modules); inspect targeted live dry runs separately. A generic verifier fixture or a successful fallback-only run does not establish a working live parser.
